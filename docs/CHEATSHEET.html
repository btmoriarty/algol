Start

init.py --root . --project NAME --compile

Writes the strong starter policy and compiles it. It already routes the high undo cost surfaces (auth, migrations, money, public API, infra, CI), so a cold first run is useful. Trim the globs to your repo.

Compile the policy

compile_policy.py .algol/policy.toml

Turns the versioned .algol/policy.toml into REVIEW.md, scanner-rules.json, routing.json, catalog.json. Deterministic; a policy change is a dated, reviewable diff.

Gate a change

gate.py --base main

Routes the change, runs the collectors on the changed files only, and reconciles into the record. Reports new vs carried; prior dispositions survive. Silent on a low-risk diff. Also --changed, --staged, --dry-run.

Route a change

router.py --routing routing.json --changed <paths> router.py ... --format commands

A recommendation per matched standard, deep-tier escalation on undo cost. --format commands prints the exact command to run each engine, silent when the change is low risk. Recommends; never launches.

Reconcile, the record

reconcile.py --collector rows.json --out record.json

One governed record. Every finding keeps its source and tier, kept distinct. Re-running with --base preserves human dispositions and their reopens-if.

The tiers

hypothesisa bare claim, no source yet
heuristica scanner or model pass fired
inferencederived from named theory
model_corr.a panel corroborated it
verifieda deterministic verifier proved it
A tier comes from a source, never from merging. Only a deterministic verifier reaches verified.

Raise to verified

verify.py prompt --finding <id> verify.py ingest out.json --finding <id>

Hand one finding to the verifier and fold the result back. uat FAIL reaches verified; gauntlet reaches model_corroborated. Never invents a tier; reports the change.

Collectors, the floor

seclint.py / brevlint.py --rules scanner-rules.json --root .

Deterministic evidence rows (CWE tagged for seclint, secrets masked). The silent floor: a finding from collectors alone is demoted, never shown as a peer of a real engine's finding.

Ingest SARIF

sarif_adapter.py results.sarif --out rows.json

Any standard tool (CodeQL, Semgrep, bandit, gitleaks, ruff) folded in through --collector, the tool name kept as the source. No per-tool code; tool-suppressed and passing results drop.

Policy check, the model pass

policy_review.py prompt --review REVIEW.md --changed <files>

Checks a change against the project's own standards, not a general bug hunt. Feed the prompt to a model, then ingest; its rows enter as heuristic.

Deep tier

reconcile.py --gauntlet run.json --base record.json

Route to gauntlet, then fold its run in. Its verdict and conditions attach to the record and seed reopens-if. Algol builds no panel; it consumes gauntlet.

Guard, report, install

wire hooks.py via hooks.example.json

A non-modifying reversibility guard before a write to an irreversible path, a collector report after. Claude Code: copy skills/algol into your skills dir. Cowork: add algol.skill via Settings, Capabilities, or build with ./build.sh.

The floor: the tool proposes; a human decides and runs the engine. No finding originates in Algol except the deterministic collector rows, and a heuristic is never silently upgraded to verified.
