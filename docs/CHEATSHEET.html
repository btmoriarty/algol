Algol cheat sheet
Governs how a project reviews code; it reviews nothing itself. Routes each change by policy and undo-cost, reconciles every engine's findings into one record, and never upgrades a heuristic to verified. The commands below are examples; run them how your repo is laid out.
✦
ALGOL
Beta Persei, the Demon Star
a review control plane
v0.16.0

Start: the strong default

init.py --root . --project NAME --compile
Writes the shipped starter policy and compiles it. The starter already routes the high-undo-cost surfaces (auth, migrations, money, public API, infra, CI) to a deeper engine, so a cold first run is useful. Defaults ship strict; trim the globs to your repo.

Gate a change

gate.py --base main
Runs one change end to end: routes it, runs the collectors on the changed files only, and reconciles into the record. Reports new vs carried; your prior dispositions survive. Silent on a low-risk diff. Also --changed <paths>, --staged, --dry-run.

Route a change

router.py --routing routing.json --changed <paths> router.py ... --format commands
A recommendation per matched standard, deep-tier escalation on undo-cost. --format commands prints the exact command to run each engine, silent when the change is low-risk. Recommends; never launches.

Reconcile & the record

reconcile.py --collector rows.json --out record.json
One governed record. Every finding keeps its source and tier kept distinct; a heuristic is never silently upgraded. Re-running with --base preserves human dispositions and their reopens-if.

The tiers

hypothesisa bare claim, no source yet
heuristica scanner or model pass fired: a signal
inferencederived from named theory (rigor)
model_corr.a panel corroborated it (gauntlet)
verifieda deterministic verifier proved it
Only a deterministic verifier reaches verified. A tier comes from a source, never from merging.

Raise to verified

verify.py prompt --finding <id> verify.py ingest out.json --finding <id>
Hand one finding to the verifier and fold the result back. uat FAIL reaches verified; gauntlet reaches model_corroborated. Never invents a tier; reports the change or that the verifier did not address it.

The collectors: the floor

seclint.py / brevlint.py --rules scanner-rules.json --root .
Deterministic evidence rows (CWE-tagged for seclint, secrets masked). The silent floor: a finding from collectors alone is demoted, never shown as a peer of a real engine's finding.

Ingest SARIF

sarif_adapter.py results.sarif --out rows.json
Any standard tool (CodeQL, Semgrep, bandit, gitleaks, ruff) folded in through --collector, the tool name kept as the source. No per-tool code; tool-suppressed and passing results are dropped.

Policy check (model pass)

policy_review.py prompt --review REVIEW.md --changed <files>
Checks a change against the project's own standards, not a general bug hunt. Feed the prompt to a model, then ingest the result; its rows enter as heuristic.

Compile the policy

compile_policy.py .algol/policy.toml
Turns the versioned .algol/policy.toml into REVIEW.md, scanner-rules.json, routing.json, catalog.json. Deterministic; a policy change is a dated, reviewable diff of how the project reviews.

Deep tier

reconcile.py --gauntlet run.json --base record.json
Route to gauntlet, then fold its run in. Its verdict and conditions attach to the record and seed reopens-if. Algol builds no panel; it consumes gauntlet.

Guard & report

wire hooks.py via hooks.example.json
A non-modifying reversibility guard before a write to an irreversible path, and a collector report after. Advises by default; blocks only under ALGOL_GUARD_BLOCK=1.

Install

Claude Code: symlink or copy skills/algol/ into your skills directory.
Cowork / claude.ai: add algol.skill via Settings > Capabilities, or build it with ./build.sh.
Then run init, and gate a change. Stdlib-only Python 3.11+.
Your data: Algol runs against your own repository. The policy and the record are plain files under version control; Algol sends nothing on its own.
The floor: the tool proposes; a human decides and runs the engine.
No finding originates in Algol except the deterministic collector rows, and a heuristic is never silently upgraded to verified.
